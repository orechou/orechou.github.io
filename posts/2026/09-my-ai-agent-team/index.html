今年年初的时候为了使用 OpenClaw，我翻出了 10 年前的两台 MacBook 来折腾。作为爆火的现象级 Agent 产品，OpenClaw 从大洋彼岸红到了国内，火到一波无意义的焦虑在国内散播。之后也折腾了 Hermes。但用下来总觉得差强人意，需要去搞一堆复杂的配置，选模型，选技能等等。

用得越多，越觉得大道至简。产品不是让大家用复杂的东西，而上述的 OpenClaw 并不好用，Hermes 也是如此。

现在我的观点是：作为个人 Agent 的搭建，CC 或者 Codex 组合 Skills 是无敌的存在，是无敌。那么如何将 CC 和 Codex 集成到你的 Agent 团队中，其实一个软件就可以了。它就是 Cumora，作者是大佬 yetone。

说实话，当狼人杀玩起来的时候，有惊讶到我，让我感觉到了我的 Agent 员工们的活人感，这或许就是未来的世界。

现在各种开各种会议的时候，我都在想为什么不能把我的 Agent 拉进会议代替我。它可以完全可以接入我的数据，克隆我的声音。我很期待所有 IM 开放的那天。
